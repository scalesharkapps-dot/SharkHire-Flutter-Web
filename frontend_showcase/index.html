The SharkHire app, screen by screen.

SharkHire matches job seekers in Pakistan and abroad to jobs from their CV. This page shows the Flutter mobile frontend as it stands today: every implemented screen, what is finished, what still runs on sample data, and what is left.

What's built

One app, three experiences

After sign-in, each role lands in its own app with its own tabs. Everything below works end to end on sample data.

Job seeker 39 screens, incl. sign-in

  • Sign up, email check and job preferences
  • Upload a CV, watch it process, correct what was read
  • Matched jobs with a score and plain reasons
  • Search with filters; save jobs
  • Apply in-app or on the employer's site
  • Track every application through 7 statuses
  • Notifications, job alerts, settings, Premium

Employer 7 screens

  • Overview of jobs and applicants
  • Post a job; it waits for admin approval
  • Fix and resubmit a rejected job
  • Review applicants and change their status
  • See a candidate's CV only after they apply
  • Company profile with verified badge

Admin 14 screens

  • Approve or reject jobs (reason required)
  • Users and employer verification
  • External listings and CV processing reports
  • Categories, skills and announcements
  • JSearch API usage against the monthly limit
  • Analytics, audit logs, platform settings

Strengths

  • Scale Shark logo, colors and fonts throughout; no copied third-party branding
  • Loading, empty and error states with Retry on every list
  • Accessibility tested: 48 px tap targets, labelled buttons, AA text contrast
  • Every job shows its source: apply in-app or on the employer's site
  • Mock data and real API code kept apart; switching is a build setting
  • Typed API errors, including rate limits and timeouts, shown as friendly messages

Fixed while preparing this showcase

  • Employer and admin overviews had an empty gap above the stat tiles on phones with a notch
  • Application progress line showed an empty box where an arrow glyph was missing from the font
  • "1 results" in API monitoring and "1 listing … are hidden" in external listings

Still to improve

  • Light theme only; English only
  • Not yet reviewed on a physical phone
